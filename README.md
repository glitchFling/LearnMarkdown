## Lesson 2: Headings

### Headings like these:

# Heading 1: Main Title (Largest - H1)
## Heading 2: Major Sections (H2)
### Heading 3: Subsections (H3)
#### Heading 4: Minor Subsections (H4)
##### Heading 5: Tiny Sections (H5)
###### Heading 6: Smallest Title (H6)

## How to use them:

For Heading 1, type in `# Heading 1`.
For Heading 2, type in `# Heading 2`.
For Heading 3, type in `# Heading 3`...

Then you do the same for Headings 4 - 6.

> [!WARNING]
> Headings can only size up to ***1 - 6.*** They cannot go up nor down any further within the limit.

## What are Code Snippets?
Code snippets `(formally code)` is a relatively small amount of source code that is stored and later inserted into a larger codebase as part of the process of writing the code.
[Learn more...](https://en.wikipedia.org/wiki/Snippet_(programming))

## What is Code? (For my sheltered developers)
Code is simply a set of written instructions that a human writes to tell a computer exactly what to do.

for example, If you want to write `javascript` or `JS` as a snippet, it would look like this;

